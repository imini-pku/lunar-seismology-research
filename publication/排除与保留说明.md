# 完整归档的保留与排除

归档日期：2026-11-08。两个原项目目录保持只读，本次没有删除或修改原文件。

## 保留

- 原有源码、配置、原始与处理数据、实际分析表、图件、研究设计、报告、本人稿件与 Supporting Information。
- h 与月球散射强度评估的目录关系、文件内容和历史版本。网页优先展示源码与主要成果，大型文件在 Release；三包解压到同一个父目录后恢复目录关系。
- 公开数据来源说明、产品标签、版本元数据与原作者代码声明，不把第三方作品重新标记为本人的许可或原创内容。
- 含问题的历史 DEM 也保留在单独压缩包。原研究已拒绝复用该文件，新 README 同样说明其历史状态，未以“完整版”名义抹去已知问题。

## 排除

| 原位置/类别 | 原因 |
|---|---|
| h 的 `tools/`、`node_modules/`、`tmp/`、`work/`、临时渲染目录、`.codex/` 等 | 本机程序、安装包、会话/中间渲染缓存或混杂私有工作区，不是研究成果。 |
| 区域散射的 `.build/`、各 `__pycache__/`、Office `~$` 文件 | 本机依赖、自动缓存与正在编辑文件的锁信息。 |
| h 的审稿回复 DOCX，以及 cover letter 和其渲染副本 | 可能包含非公开审稿人原文、编辑往来与个人联系方式。本人论文与 SI 本身完整保留。 |
| `月球散射强度评估/docs/参考文献/`，第三方论文全文 TXT/PDF，第三方稿件 ZIP | 第三方全文库及其下载/浏览元数据；相应引用、来源说明和本人的研究报告保留。 |
| 原 `outputs/综合研究设计_20261029/月球散射研究设计_完整文档与图表.zip` | 旧重复 ZIP 内含第三方论文全文抽取。该包中的本人报告、图件和明细在当前原项目目录中保留，不另公开含第三方全文的旧包。 |

拥有 `reviewer` 字样的本人分析代码、敏感性分析表和科研图件未因文件名被一概移除；它们与私密审稿信件分别处理。没有删去大型原始数据来制造小体积“演示版”。

对选入文件及其文档/ZIP 内文本条目进行了密钥模式扫描，未发现高置信私钥、GitHub token、OpenAI key 或 AWS key。论文正式通讯字段和公开作者声明原样保留；这项扫描不是对所有潜在敏感信息的无限保证。

每个完整包的原文件数、原始字节数、压缩后字节数和 SHA-256 保存在 `release_assets_manifest.json`，包内另有逐文件清单。原文件未被摘要或新建合成示例替代。
