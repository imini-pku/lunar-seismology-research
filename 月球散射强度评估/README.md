# 月球散射强度区域化评估

这个项目承接“起伏月表对月震波传播影响”的四模型数值实验，下一步把问题推进到：**盆地/平原、陨石坑、高地等不同地貌单元中的月震波散射强度是否可被区分、区分到什么程度，以及这种差异能否被 Apollo 长窗记录和可控合成实验共同支持。**

当前目录是新建的分析项目。旧项目仍保留在 `C:/Users/Administrator/Desktop/起伏月表影响数值模拟`，本项目只保存规划、输入规范、可复现的首轮反演脚本和结果索引，不复制大型 NetCDF、SAC 或论文附件。

## 当前基线与边界

- 已有四因子实验：平坦/起伏地表 × 无/有浅层随机非均质；已有台站级峰值、能量、T90、分量占比、主频和路径地形指标。
- 已有 A16/S12 路径低洼段分析，但目前只保留一个方向校正后的 crater-like depression，不能支撑“所有陨石坑具有统一衰减规律”。
- 现有生产模拟主要约 250–400 s，而 Apollo 长尾延伸到约 3000 s；现有结果只作为早期波形和前向标定证据，不能直接当作长尾散射参数。
- 旧模拟缺少完整的运行清单、随机种子及部分数值参数的共置记录。补齐这些信息是区域反演的 P0 门槛。
- 已核验的 M1–M6 和半空间 `station.nc` 外置路径、时长与 SHA-256 已登记在 [`config/known_synthetic_inputs.csv`](config/known_synthetic_inputs.csv)；这些文件本身不含完整模型属性，仍需关联工程脚本补全运行清单。
