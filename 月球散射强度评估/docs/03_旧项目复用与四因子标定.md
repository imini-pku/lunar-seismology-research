# 旧项目结果如何进入新反演

旧项目的 M1–M6 和半空间剖面数据可以直接支持方法验证、窗口选择、前向代理标定和数值边界审计，但不应直接被当作盆地、陨石坑或高地的观测样本。

对每个区域化合成单元，沿用四因子差分：

`Δ_topo = y(topography,no-heterogeneity) − y(flat,no-heterogeneity)`

`Δ_sub = y(flat,heterogeneity) − y(flat,no-heterogeneity)`

`Δ_int = y(topography,heterogeneity) − y(topography,no-heterogeneity) − y(flat,heterogeneity) + y(flat,no-heterogeneity)`

这三个量分别衡量地形、浅层体散射和非加和交互。新项目应在每个候选区域、频带和时间窗重复四因子设计；如果只具备一个或两个模型单元，则不得把差值解释成已分离的机制。

现有外部 `station.nc` 路径和校验和已登记在 `config/known_synthetic_inputs.csv`。这些 NetCDF 内部没有完整运行属性，因此模型参数、网格、边界、震源、接收器和随机种子必须从工程脚本或提交档案补回 `config/run_manifest_template.csv`，不能从波形文件反推。

现有输出长度约 250–400 s；它们可以支撑 `50–245 s` 共享窗和早期波形比较，但不能替代 `1000–3000 s` 长尾模拟。正式区域反演需要把输出延长到至少 3000–5000 s，并做能量闭合、吸收边界和网格收敛测试。
