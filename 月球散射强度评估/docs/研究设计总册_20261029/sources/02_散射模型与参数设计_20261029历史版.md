# 第二册｜散射模型、参数范围与物理实现

版本：2026-10-29，综合设计版。本文给出模型定义和实施规格；正式CGFD3D传播计算尚未开始。证据编号与原文定位见[第五册](05_文献依据与论文组织.md)，逐项选择见[36项来源表](tables/model_choice_provenance.csv)。

## 1. 研究目标与可检验假设

研究对象是人工撞击产生的弹性波在月球浅部非均质结构和真实起伏地表中的传播。先回答：**同一统计介质能否同时解释多条实际记录路径？增加横向或区域差异，能否改善未参与拟合事件的预测？**随后再讨论地貌关联。

以下是假设，均不是已获得的结论：

| 假设 | 对照方式 | 否定或保留的条件 |
|---|---|---|
| H0：共享背景与共享散射统计足以解释观测 | 所有合格事件使用共同a、σv、H，事件源参数各自共享于其所有台站 | 若跨事件预测失败且不能由源、时标、响应解释，再增加结构自由度 |
| H1：真实地形会影响所需地下扰动强度 | 平坦/LOLA与无/有随机介质构成四组控制 | 对比参数集合和预测误差，不能只比较一条峰值归一化曲线 |
| H2：S12/S14路径需要差异化结构 | 共同事件下比较共享模型与有限区域偏差模型 | 新参数必须提升完整留出事件的预测，并超过随机种子和处理误差 |
| H3：层厚或源侧/接收侧分布比增大σv更关键 | 固定a、σv，对比H(x,y)和扰动位置 | 对早期增强、峰时、晚尾与不同距离的变化给出一致解释 |
| H4：S15近距路径可迁移S12统计规律 | 在A15LM→S15上外推，再允许受限调整 | 同时检验LM源及场地，避免将源差异归入地下介质 |
| H5：长距记录需要更深或更广的散射区 | 局部模型预测远距资料，与独立深层分支比较 | 先验证几何和计算域；失败不自动证明S16接收区最强散射 |

统计单元是事件、接收器集合、频带和有效时间窗。接收站周围的地貌名称不代表全部传播路径，也不等同于反演参数分区。S12/S14可以联合建模，保留两个独立接收站。

## 2. 参数约定和不可互换的物理量

取背景速度为Vₛ₀，定义相对剪切波速度扰动qₛ=δVₛ/Vₛ₀，单位方差随机场η：

\[
V_S(\mathbf x)=V_{S0}(\mathbf x)[1+q_s(\mathbf x)],\qquad q_s=\sigma_v w(d)\eta(\mathbf x).
\]

这里σv是强扰动平台内的目标相对标准差，d为约定深度，w为0–1深度权重。必须同时保存生成参数、实际样本均值、实际RMS、最小值、最大值及随深度的统计；有限体积内实际RMS不一定严格等于输入σv。

| 符号 | 定义、单位 | 比较时必须保留的限定 |
|---|---|---|
| a或aₓ、aᵧ、a_z | 给定自相关/功率谱中的相关尺度，km | 不是陨石坑直径、碎块尺寸或散射平均自由程 |
| σv | 相对速度扰动标准差，无量纲 | 5%写为0.05；与最大幅度、峰峰值、生成器ε分开 |
| ν | von Kármán谱形参数 | ν=0.5为本定义中的指数自相关特例；改变ν也改变高波数能量 |
| H | 本项目R1渐消中心深度，km | 与强扰动平台底和完全归零深度相差半个渐消宽度；不同论文的H须先对齐定义 |
| Qᵢ | 内禀吸收品质因子 | 不等同尾波Q_c、散射Q_sc；QP/QS通常表示P/S波Q |
| D、ℓ* | 扩散系数km²/s、输运平均自由程km | D=v_Eℓ*/3仅在相应三维各向同性输运近似下成立；不能据此唯一确定a、σv |
| βρ | 密度相对扰动对速度扰动的比例 | βρ=0.8是项目敏感性设定，不能作为月球测量值引用 |

例如有界均匀分布U[−δmax,δmax]才有σ=δmax/√3。平滑、截断、深度权重或不同概率分布都会改变换算；本文不将文献“最大±50%”改写为“RMS50%”。〔O21、O22、N24、G17、SE18〕

## 3. 背景速度、密度与场地

### 3.1 S12参考背景B0

当前材料预览采用Onodera2022上月壳密度—孔隙度—速度关系作为S12参考，深度d以米表示：

\[
\rho_0(d)=2308+786[1-\exp(-d/9800)]\quad\mathrm{kg\,m^{-3}},
\]
\[
\phi(d)=1-\rho_0(d)/3094,
\qquad V_{P0}(d)=7150\sqrt{1-\phi}\,
\exp\left[\frac{(\phi/2-\xi)\phi}{2(1-\phi)}\right]\quad\mathrm{m\,s^{-1}},\quad \xi=7.
\]

依据：O22 §2.3式(1)–(4)，密度相关依据为Besserer2014〔B14〕。这些关系不构成S14/S15/S16各自的实测结构。

现有预览以Vₚ/Vₛ=2作为浅部起点，10–12 km之间线性过渡到√3。**该2 km过渡区是本项目的平滑选择。**固定背景时要与所有随机介质、地形对照共用；若改变背景，整组模型一同重算。不能通过只替换某个“差模型”的背景制造不公平比较。

### 3.2 独立背景B1/B2及浅部场地S

| 分支 | 依据 | 使用方式与状态 |
|---|---|---|
| B0：上述S12参考 | O22、B14 | 主起点；已有小体积材料预览，尚非正式计算域 |
| B1：独立月球一维模型 | Garcia2019及作者公开模型〔GA19〕 | 先采用完整均值模型；数值表尚未接入本项目，不猜填速度界面 |
| B2：VPREMOON | Garcia2011及2012勘误〔VP12〕 | 必须以勘误Table6核对半径、速度、密度、QP/QS与固定参数 |
| S：近站浅层 | Amrouche2022、Sollberger2016、Keil2024〔AM22、SO16、KE24〕 | 仅作为局部低速层/场地竞争分支；米级高频主动源模型不能填满百公里路径 |

背景反演的逐深度±1标准差，不等于短尺度速度非均质σv，也不构成一个保留深度协方差的联合后验样本。B0目前未含完整莫霍和地幔；长距、深层R5及长尾计算必须先补全背景，不能在25.5 km材料预览底部直接截断并解释深传播。

## 4. 随机场的数学定义与生成规范

### 4.1 自相关与功率谱

首轮采用各向同性指数协方差：

\[
C_q(r)=\sigma_v^2\exp(-r/a),\quad a=r_{1/e}.
\]

三维von Kármán谱采用角波数k，单位rad/m：

\[
P(\mathbf k)\propto[1+(a_xk_x)^2+(a_yk_y)^2+(a_zk_z)^2]^{-(\nu+3/2)}.
\]

ν=0.5且三轴相同得到上述指数模型；一般ν下a不恒等于1/e距离。以白噪声傅里叶谱乘以√P生成场，所以滤波振幅的幂是−(ν+3/2)/2，不能误把P直接乘到振幅上。空间频率若为cycles/m，须乘2π转换。〔SE18；月球应用O22〕

高斯竞争场若采用C(r)=exp[−(r/a_G)²]，其谱为exp(−a_G²k²/4)。比较时锁定相同RMS及明确的尺度标准，再比较实际ACF/PSD；不得把换谱形造成的变化解释成单独a变化。

### 4.2 可复现生成步骤

1. 固定物理坐标、长度单位、网格、谱形和随机数种子；空间索引顺序明确为z、y、x。
2. 在有足够外扩的母体体积生成场，去直流分量，按目标方差归一化，然后裁取实际区域。外扩范围需要ACF检查，不能机械沿用预览中的24格。
3. 保存η，再施加深度权重和速度/密度关系。不同地形和源的控制组使用同一物理实现。
4. 按深度带检查均值、RMS、三方向线性非周期ACF、谱转折和高波数截断；同时检查Vp、Vs、ρ和体积模量为正。
5. 不用裁切极值“修好”不稳定模型而不报告。若采用有界或对数正值参数化，应视为新的分布分支，重新核查RMS与谱。
6. 重叠事件域从同一母体场取样；仅使用相同seed但改变FFT体积，不能保证两块重叠区有相同介质。母体尺寸过大时需设计可重现的空间谱/块生成方法并验证接缝。
7. 更换网格时尽量保持同一连续物理场的离散表示；否则网格误差会与随机实现差异混在一起。节点独立噪声会随网格改变物理相关尺度，不能作为固定a模型的收敛试验。

这些是项目实现与验收规格。已有材料预览只验证部分步骤，不意味着生产模型已全部达标。

## 5. 地形、深度与随机场如何耦合

LOLA描述地表h(x,y)，η描述地下材料，两者分开保存。坐标建议采用月球参考球/局部东—北—上物理坐标；CGFD3D曲线网格坐标须通过明确的映射接入，不能将经纬度直接当公里。

设计两个深度定义：

- **主分支Dsurf：**d=h(x,y)−z，为当地地表下的垂向深度，扰动层随地形起伏。这里是竖直深度，不自动等于地表法向距离。
- **控制分支Dref：**d=z_ref−z，相对于统一参考面，界面不随地形平移。用于检验“界面随地形变化”是否贡献了额外效应。

同一坐标处η固定。改变地形后，哪些点处于固体及其d可能改变，材料权重也随定义改变。因此四组地形控制仍需说明“表面几何变化”和“层界面变化”的耦合；必要时增加Dref对照，不把二者全部归为表面散射。

R1采用宽度w_H=1 km的余弦渐消，H定义为过渡中心：d≤H−w_H/2时w=1；d≥H+w_H/2时w=0；中间

\[
w(d)=\tfrac12\{1+\cos[\pi(d-H+w_H/2)/w_H]\}.
\]

所以H=10 km对应9.5 km以下开始渐消、10.5 km完全归零。文献“约10 km强散射深度”是建模启发，**1 km宽度和这一H约定由项目选取**。对已有预览以其文件属性为准，不能将新文字定义倒写成文献原值。

实施顺序建议为R0/R1→R2/R3/R7与浅层S→R6→R4/R8→R5。顺序是数据和计算预算驱动的项目安排。R5所需深度可能远超当前局部模型；其定义、分布、谱和深背景都应单独验证。R8中的ε未核实前，不转换为本项目σv。

对于R3，两层应分别定义ACF、RMS、层界和过渡；用两个场混合时，权重平方会影响总方差，不能假设线性混合仍保持目标RMS。相邻层是否相关也是模型选择，首轮固定并记录。原文28%/14%上限与本项目拟议10%/5% RMS属于不同版本。

R7的源侧、接收侧和沿途窗须在看拟合结果前定义地理形状、边缘渐消及扰动体积。几何窗不是地质分区；若比较不同体积，需同时报告体积变化和σ变化，以免把扰动总量差当成位置效应。盆地/喷出物等实质地质边界需要独立地图约束。

## 8. 源模型与吸收作为独立干扰项

NASA表给出的LM入射角约3°–5°，S-IVB约55°–79°，源族差异不能忽略；角度相对于水平面。源时刻为地面接收时刻，A16 S-IVB另有约4 s不确定性。〔NASA-I〕

源控制至少包括：等效各向同性矩张量、具有方向性的等效力、源时间函数持续时间及幅度。O22提供相关人工撞击模拟先例；这些等效表示不能被直接称为已经测得的真实源机制。地理入射方位、动量及能量耦合效率未核实前不猜填。

同一个事件的所有台站共用源参数。允许每条路径单独改变源幅度或源持续时间，会吸收真实的路径差异，使区域比较失去意义。LM与S-IVB分组做敏感性；先用同族源检验介质，再跨源族预测。

观测振幅未完成增益核定时，可以先评价形状、峰时及经统一归一化的分量分配，但要说明无法由此约束绝对能量。不得将撞击动能直接等同地震辐射能，或借自由站点放大项掩盖响应错误。

Qᵢ在每个子带上先采用可追溯的固定分支，随后检验其与H和σv的权衡。CGFD3D实际衰减实现、参考频率、松弛机制及可表示频带须由运行配置确定。只是在弹性结果上乘指数衰减，不等价于完整黏弹性传播；若用作快速诊断应单独命名。

## 9. 分区域的设计与允许结论

| 研究单元 | 首批数据 | 建模方式 | 当前能支持的表述 |
|---|---|---|---|
| S12参考走廊 | A14/A16 S-IVB→S12 | B0+R0/R1，先公共频带，再处理允许的扩展带 | 最有直接三维参数依据的起点，不等于已经得到本项目最优模型 |
| S12/S14联合走廊 | A14LM、A15SIVB及A16SIVB共同事件 | 同源联合、保留独立站点与分量，先共享后增加受限结构偏差 | 可以检验路径/场地差异；S14故障与削顶必须单独处理 |
| S15盆缘近距 | A15LM→S15 | 迁移R1并控制LM源、背景及S；再比较R7 | 单条近距路径参数非唯一，不能独立宣称盆缘通用参数 |
| S16及其他远距 | A17SIVB→S16等 | 在球面或充分验证的几何中外推；必要时独立R5 | 检验局部模型的外推能力；不能把851 km路径完全归于站下高地 |

A12/A14联合不会自动提供某个“陨石坑区域”独立样本。当前目录尚未建立特定陨石坑内/外路径的匹配实验。若论文要比较“月海—坑区—高地”，必须另补地质分区、源站穿越关系、样本量和源/距离匹配，不能把现有彩框改名就满足要求。

## 10. 实现与材料验收清单

每个材料体必须记录：背景ID及来源、坐标和深度约定、DEM版本、网格、ACF/PSD公式、a与ν、目标/实际σ、H与渐消、分布及截断、Vp/Vs/ρ耦合、源侧/站侧窗、随机实现ID、文件SHA-256。

验收至少覆盖：无NaN和非物理负值；μ=ρVs²>0及K=ρ(Vp²−4Vs²/3)>0；单位与维度；界面和网格变形；三方向相关尺度；分层RMS；共同区域一致性；网格变化后的谱稳定性。生产材料还须通过CGFD3D读入与简单波传播测试。

目前3个NetCDF只是9.5×9.5×25.5 km、100 m间距的规则网格预览，未含真实地形、完整源站范围或深部结构。预览QA通过能支持生成器的部分正确性，不能证明数百公里域和长时间波形已经收敛。详见[第四册](04_CGFD3D模拟与验证流程.md)。
