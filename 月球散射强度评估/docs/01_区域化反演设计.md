# 区域化散射反演设计

## 1. 观测量

对事件 `e`、台站 `s`、频带 `b` 和时间窗 `w`，从三分量速度记录提取包络和摘要量：

- 三分量和 Z/R/T 分量的窗口能量、RMS、峰值及峰值时间；
- `T90`、`t50`、`t95`、晚时能量比例和主频/谱质心；
- 包络的对数能量或对数 RMS，保留平滑窗口、滤波器、归一化和缺失状态；
- 事件类型、震级/能量代理、震源位置和深度、台站位置、震中距、方位角、SNR、仪器和质量旗标。

早期 `50–245 s` 用于同一事件的源幅度和台站尺度校正；尾波窗用于估计相对衰减。绝对能量只在仪器响应、速度单位、源项和三分量定义均被核验后使用。

## 2. 路径参数化

从 DEM 与地质单元沿每条震源–台站路径计算：

`L_es,R`（区域 R 的路径长度）、穿越比例、平均高程、绝对坡度、11 km 粗糙度、起伏幅度、最大坡度、低速层/风化层厚度和分类置信度。

使用路径长度而非单一台站标签来估计区域效应；台站地貌类别作为独立的 site covariate。对同一事件或同一台站的记录采用 cluster bootstrap 或层次模型，不能把相邻台站当作完全独立样本。

## 3. 物理模型

推荐的区域化观测方程为：

`y_esbw = μ_b,w + u_e,b + v_s,b − γ_b log(Δ_es) − Σ_R L_es,R k_R,b − τ_w α_b + z_es β_b + ε_esbw`

其中：

- `y` 是相对参考模型的对数能量/包络指标；
- `k_R,b` 是首轮散射强度代理，单位为 `km⁻¹`；
- `α_b` 表示内禀衰减或吸收的共同项，先固定或给强先验；
- `γ_b` 是几何扩散项；
- `z` 包括高程、路径平均坡度、起伏幅度、方位和地形分辨率等协变量；
- `u_e`、`v_s` 是事件和台站的随机效应；
- `ε` 使用稳健误差，并按事件/台站聚类估计不确定性。

包络前向模型可用扩散近似作低维代理：

`I(t,r) ∝ t^(-3/2) exp[-r²/(4D_R t)] exp[-t/τ_R]`，`D_R ≈ v_g ℓ*_R/3`。

CGFD3D 波形用于把 `sigma_vp/vs`、相关长度 `a`、低速层和地形粗糙度标定到 `k_R` 或 `ℓ*_R`，不能直接把某个随机实现的 `sigma=0.09` 当成 Apollo 观测反演值。

## 4. 反演顺序

1. **参考校正**：同事件、同台站、同频带优先采用 flat/no-heterogeneity 或局地平滑参考；否则使用早期窗的事件/台站随机效应。
2. **首轮代理拟合**：分频带、分时间窗拟合 `k_R`、距离项和事件/台站效应；脚本输出 Huber 稳健线性估计和自助法区间。
3. **合成双胞胎**：给定已知 `k_R`，重复完整处理和拟合，检查回收偏差、区域交换和路径稀疏时的失真。
4. **层次贝叶斯**：双胞胎通过后再加入 `Q_c`、频率幂律 `k_R(f)=k_0(f/f_0)^η`、区域间平滑先验和地貌分类概率。
5. **留出验证**：按事件、台站和区域分别留出，报告后验预测包络、能量、T90、分量比和峰时，而不是只报告训练集残差。

## 5. 必须做的敏感性

- 频带和包络平滑：10/20/40 s；
- 早期/过渡/晚时窗边界和右删失；
- DEM 分辨率、路径方向和地质分类版本；
- 随机介质 `sigma`、相关长度 `a`、低速层厚度、`Q`、源深/源机制；
- 网格、时间步、吸收边界、域尺寸、运行时长和随机种子；
- 只保留具有足够独立事件–台站路径的区域，报告筛选日志。

## 6. 解释限制

区域参数是路径积分意义上的有效参数。陨石坑出段后的波场包含此前路径记忆，不能解释为单次局地透射系数；单个低洼段、单条剖面或单个 Apollo 事件不能支撑普遍陨石坑定律。数值边界反射、几何扩散、内禀衰减和散射必须通过前向实验或能量闭合测试分开。
