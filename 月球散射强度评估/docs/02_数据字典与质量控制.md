# 数据字典与质量控制

## 长格式指标表

首轮反演读取 `data/processed/metrics_long.csv`。一行对应一个事件–台站–频带–时间窗组合。必要字段见 `config/metrics_long_schema.csv`。

最少需要：`event_id`、`station_id`、`region_id`、`frequency_hz`、`window_start_s`、`window_end_s`、`distance_km`、`log_energy_obs`、`log_energy_ref`、`sigma_log_energy`、`path_length_total_km`、`path_coverage_fraction`、`segment_count`，以及每个区域的路径长度列 `path_km__<region_id>`。如果没有参考能量，必须把 `log_energy_ref` 留空并在审计中说明，脚本不会将原始绝对振幅默认为可比。

`region_id` 表示用于本行拟合的路径主类别；`station_region_id` 单独表示台站所在单元。一个事件–台站路径可以同时有多个 `path_km__*` 列，不能把主类别当作路径唯一地貌。总路径长度和分类覆盖率用于检查区域分段是否闭合；分类不确定时填写 `classification_confidence`，在层次模型中作为权重或蒙特卡洛抽样输入。

## 质量旗标

以下任一项失败时，记录保留在 QC 表但不进入主反演：

- 仪器响应、极性、三分量方向或时间基准未核验；
- 削顶、缺道、明显仪器异常、SNR 不足或事件/台站定位超出阈值；
- 时间窗超过实际记录长度，或依赖未经声明的零延伸；
- 频带低于 Nyquist、波长未被网格充分分辨、吸收边界反射进入窗口；
- 区域分类只有一维剖面证据，尚未完成二维形态或正式目录核验；
- 同一事件/台站重复记录未标记，导致伪增大样本量。

## provenance

每个数据表和图件必须记录：原始文件路径、文件校验和、处理脚本版本、滤波器、采样率、时间窗、包络平滑、归一化参考、缺失值规则、区域目录版本、DEM 版本和运行参数。任何从旧项目复制的结果要标注“旧项目派生结果”，并保留原路径。
