# 项目路线图：从起伏地表效应到区域散射强度

## 研究问题

目标不是给每个地貌类型贴一个固定的“散射强/弱”标签，而是估计在控制震源、距离、台站响应、内禀衰减和路径几何之后，各区域对波场包络和尾波能量的附加散射效应。核心比较为：

1. 盆地/平滑平原、陨石坑及其壁/缘/喷出物、高地三个目标区域之间的 `g_R(f)` 是否存在可重复差异；
2. 差异主要出现在早期直达波、过渡段还是晚时尾波；
3. 地形起伏、浅层随机非均质和低速层是否存在区域依赖的交互；
4. 观测 Apollo 记录能否在不把数值边界反射误认为散射的前提下支持这些差异。

## 阶段门与交付物

| 阶段 | 主要工作 | 通过标准 | 交付物 |
|---|---|---|---|
| P0 | 旧项目审计、数据清单、运行参数和时间窗核验 | 每个输入有来源、校验和、单位和缺失说明 | `config/run_manifest.csv`、审计报告 |
| P1 | 区域目录与路径分段 | 每个区域有几何定义、版本、覆盖率和分类置信度；区域间有足够独立事件/台站路径 | 区域目录、DEM/地质图版本、路径长度表 |
| P2 | Apollo 长窗预处理 | 仪器响应、极性、方向、时间基准、SNR、削顶和缺道检查通过 | 原始到处理后的 provenance、QC 表、三分量波形索引 |
| P3 | 区域化前向实验 | 每区至少 flat/no-hetero、flat/hetero、topo/no-hetero、topo/hetero；随机种子≥10；正式区域前向输出至少 3000 s；另做能量闭合和边界收敛审计 | 区域合成库、运行清单、网格/时间步/边界收敛报告 |
| P4 | 合成标定与双胞胎恢复 | 已知 `g_R`、`Q_c` 能在留出随机种子和事件上回收；设计矩阵条件数可接受 | 标定曲线、恢复图、参数可辨识性报告 |
| P5 | 区域反演 | 先固定 Q 和源项，仅释放 `g_0/Q_c`；再做带先验的多参数反演 | 后验/稳健估计、95% 区间、事件/台站/区域留出结果 |
| P6 | 物理解释与论文 | 每项结论能回溯到数据表、模型和图；明确随机介质、内禀衰减、几何扩散与边界误差 | 主文图、补充材料、结果—证据矩阵 |

P0–P2 可以并行推进；P3 未通过前不把观测拟合写成区域物理参数；P4 未通过前只报告代理量。

## 区域设计

首轮建议四类而不是直接按单个地名分组：

- `basin_plain`：盆地内部或平滑平原，作为低起伏参考；
- `crater_floor`、`crater_wall_rim`、`crater_ejecta`：陨石坑底、壁/缘和喷出物分别编码，样本不足时再用层次模型合并；
- `highland_rough`：高地或高起伏古老地形；
- `reference_smooth`：与目标区域距离、方位和高程相近的平滑对照段。

站点所在单元和震源–台站路径穿越单元必须分别记录。区域分类先依据 LOLA/SLDEM DEM 与 USGS/LPI 地质图，之后用二维形态（圆形度、壁坡、中心洼地、喷出物范围）核验陨石坑。只有正式目录和二维核验均通过，才使用具体陨石坑名称。

## 首轮参数策略

第一轮只估计每个区域、每个频带的散射代理 `g_proxy_R,b`，并固定或强先验约束 `Q_i`、源幅度、几何扩散和仪器校正；第二轮才释放 `Q_c`、低速层厚度或随机介质 `sigma_v/a`。否则 `g_R`、内禀衰减、源项和路径长度会产生严重退化。

推荐先复现旧稿可比的 `0.3–0.9 Hz` 基线，再根据 Apollo 仪器响应、SNR 和数值网格分辨率扩展到 `0.1–0.3 Hz`、`0.9–1.5 Hz` 等频带。时间窗至少保留 `50–245 s` 早期公共窗、`245–1000 s` 过渡窗、`1000–3000 s` 晚时窗；若记录或模拟不足，必须标记右删失，不能零延伸后再称为完整尾波。

## 论文主线

科学链条应保持为：地貌分类 → 路径分段 → 可控前向实验 → 合成标定 → Apollo 多事件/多台站反演 → 独立验证 → 区域散射解释。现有四模型结果用于说明起伏地表与浅层非均质的可分离效应和先验范围；它们不能单独证明盆地、陨石坑或高地的绝对散射系数。
