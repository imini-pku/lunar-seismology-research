# 论文大纲与工作流程

## 建议题目

**Regional Variations in Lunar Seismic Scattering Across Mare, Basin-Margin, Crater, and Highland Terrains**

中文工作题目：**月海、盆地边缘、陨石坑与高地区域的月震散射差异**。

## 论文大纲

### 1 引言

说明月震长尾和强散射对月球内部结构、震源定位和未来月震台网的影响；指出前人已建立全球平均散射模型，但没有系统比较不同地貌单元。提出三个问题：区域散射是否不同、差异是否具有频率依赖、地形和浅层破碎结构能否被分开。

### 2 背景与前人工作

2.1 Apollo PSE 网络、事件类型和数据质量；

2.2 单次散射、辐射传输和扩散模型；

2.3 `Qc`、`Qi`、`Qsc`、`D`、`ℓ*` 的定义和不可直接互换性；

2.4 megaregolith、月海、盆地边缘、陨石坑和高地的结构差异；

2.5 前人全球平均、局地台站和三维模拟结果；

2.6 本文的区域化缺口和研究假设。

### 3 区域、数据与研究设计

给出 Apollo 12/14/15/16 和候选区域地图；展示 DEM、地质 polygon、陨石坑目录和路径分段。说明 DMQ 用于近站散射比较，SMQ/撞击用于路径积分。列出事件、台站、频带、时间窗、SNR 和质量筛选。

### 4 观测处理与散射指标

仪器响应、极性、三分量方向、glitch/spike/校准信号和 A14 系统性畸变检查，随后去趋势、去毛刺和带通；计算包络、窗口能量、RMS、峰值时间、上升时间、T90、`Qc` 和频带能量比。所有窗口保留右删失标志，不能用零延伸伪造长尾。

### 5 前向模型与区域参数化

建立均匀基线、地形修正模型和三维随机介质模型。区域参数优先用 `Qsc_R(f)` 或 `D_R(f)`，地形、浅层破碎层和交互项分开设置。用四因子合成校准观测指标到物理参数的映射。

### 6 反演方法

对事件–台站–频带–窗口使用路径积分模型：

`y_esbw = event_effect + station_effect + geometry + Σ_R L_es,R θ_R,b + covariates + error`

先用稳健 GLS/Huber 得到初值，再用事件和台站随机效应的层次模型或 Bayesian posterior 估计区域参数。比较模型为：无区域差异、仅地质分区、仅地形、地形+地质+交互。

### 7 结果

给出区域覆盖、质量控制、合成恢复、各区域 `Qc/Qsc/D` 和频率依赖、跨边界差异、事件类型差异以及留出事件预测。结果部分只报告估计值和区间，物理解释放到讨论。

### 8 讨论

讨论地貌、破碎层、月壤厚度、几何聚焦和内禀衰减的相对作用；比较全球平均与区域结果；说明哪些区域只能给上限或相对排序。重点处理台站稀疏、震源定位、源强和仪器响应的不确定性。

### 9 结论与未来工作

回答区域差异是否可识别、哪些区域最适合未来月震网和着陆任务、结果能否迁移到月球背面或其他行星。

## 工作流程

`文献与假设注册 → Apollo/PDS事件目录 → 波形质量控制 → DEM/地质/陨石坑分区 → 震源–台站路径交集 → 指标提取 → 区域覆盖审计 → 合成双胞胎 → 前向标定 → 单区域试反演 → 联合层次反演 → 留出验证 → 图表和论文`

## 阶段安排

| 阶段 | 工作 | 退出条件 |
|---|---|---|
| W1 | 综述、参数定义、事件类型和候选区登记 | 每个参数有定义和引用，明确 `Qc` 与 `Qsc` 不混用 |
| W2 | 下载 Apollo/PDS 数据、事件目录和台站元数据 | 至少 A12/A15/A16 三个长期台站可处理 |
| W3 | DEM/地质/陨石坑 polygon 与路径交集 | 每个目标区有独立事件、台站和距离覆盖 |
| W4–W5 | 观测指标和质量控制 | 通过 SNR、仪器、方向、时间和右删失审计 |
| W6–W8 | 区域四因子合成和参数敏感性 | 合成双胞胎能回收区域相对差异 |
| W9–W10 | 单区域稳健反演 | 设计矩阵满秩，后验不贴边，留出误差可接受 |
| W11–W13 | 多区域层次反演和敏感性 | 结果对频带、窗口、DEM 分辨率和源类型稳定 |
| W14–W15 | 图表、讨论、数据和代码整理 | 每个定量结论均可追溯到数据和脚本 |
