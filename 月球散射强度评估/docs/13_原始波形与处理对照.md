# Apollo人工撞击记录：先看原始波形，再看处理结果

更新：2026-10-29。本页是本轮波形检查入口，承接项目中的地形与散射模型报告。范围为9次人工撞击、21个事件—台站配对。这里展示原始档案和可追溯处理结果，不把新的显示方式当成已经完成的反演质控。

## 1. 应先看什么

建议按以下顺序阅读：

1. **第3节：全部原始记录。**保留原始数字计数DU、直流偏置、尖峰和可疑削顶；不去响应、不滤波、不归一化。横轴使用档案的名义采样时间。
2. **第4节：处理后的记录。**同一组台站和三分量，展示名义响应校正后的0.3–0.9 Hz速度。此时横轴使用ATT校正时间，单位也已改变。
3. **第5节：同一时间轴上的三阶段对照。**每个配对按“原始计数→响应校正速度→带通速度”分列；三列统一使用ATT时间轴，原始振幅仍保持原值。这里最适合定位处理引入的变化。
4. 查看另列的**0.3–0.5 Hz位移参照**，与已有论文常用的窄带比较方式衔接；它不是0.3–0.9 Hz速度图的另一种单位标法。

## 2. “原始”与“处理后”分别意味着什么

### 2.1 原始档案及逐点核验

原始数据来自EarthScope发布的XA Apollo档案，21个MiniSEED文件保存于[data/raw/impact_modern](../data/raw/impact_modern/)。该档案已经历发布者的恢复和时间整理，因此“原始”在本报告中指**本次下载档案中的未去响应数字计数**，不是未经任何档案恢复的遥测磁带比特流。[Nunn et al., 2022](https://doi.org/10.3847/PSJ/ac87af)

本轮重新从MiniSEED读取各道，并与此前处理文件中的`raw_counts`逐点比较：60条已有记录的数字计数、缺口掩码均一致。原始档案文件哈希及逐道核查见[原始记录完整性审计](../results/waveform_raw_integrity_audit.json)。

- DU是仪器数字计数，不是地面位移或速度；保留约数百DU的偏置是正常的原始显示方式。
- `−1`为缺样标识，不绘制成真实振幅；0和1023仍保留为实际返回的计数，可疑轨值或平台需要检查，不能直接当作缺测。
- 各道纵轴可有不同刻度，图中不做逐道峰值归一化；即使都以DU表示，不同站、分量和增益状态的绝对地面振幅也不能据此直接比较。
- MHZ是垂直分量，MH1/MH2是仪器水平分量；本轮未旋转成径向/切向分量。
- A16 S-IVB、A17 S-IVB、A17 LM三次事件的S14 MHZ在本次下载档案中**没有返回**，同时落在已知故障时段。图中保留占位说明；不能将其表述成“已有波形被绘图隐藏”。

### 2.2 两种时间轴

原始总览使用MiniSEED名义时间。三阶段对照和处理总览使用ATT时标的局部仿射校正时间；仅修正样点的时间坐标，没有在本轮对原始计数重采样。两种图都以NASA给出的地面接收撞击源时刻为零，没有额外减去约1.3秒月地传播延迟。

因此，不能把原始总览与处理总览中的亚秒至数秒差异直接解释为物理相位移动。判断处理前后的细节变化，应使用第5节已经统一时间轴的对照图。ATT局部拟合、响应所用标称采样率及完整增益历史仍属于需要进一步核验的环节。

### 2.4 本轮的处理链与图中标识

主速度链为：原始计数→仅对最多2个样点的缺口作临时线性插值→按更长缺口划分连续段→对至少60秒的段去线性趋势和均值→3%渐消与名义响应校正→0.3–0.9 Hz带通→恢复原始缺口掩码。带通采用Butterworth N=4设计，并作前后向零相滤波；不能将N=4理解成前后向组合后的总阶数。响应校正使用四角预滤波[0.05, 0.1, 1.5, 2.0] Hz、输出VEL、不开water-level。这里的预滤波四角不是最终带通边界。

另存0.3–0.5 Hz速度，供相同物理量的频带比较；独立位移分支采用官方示例的[0.1, 0.3, 0.9, 1.1] Hz预滤波、输出DISP后再作0.3–0.5 Hz带通。位移分支沿用本项目3%渐消和缺口策略，不能称完全复制官方示例。

这次每个原始连续段只执行一次完整处理链，不再“响应后裁边→剩余段再按60秒筛选→滤波再裁边”。但不把因此显示出来的样点直接认证为可反演数据：

- **灰色缺口条：原始缺样。**在所有处理中继续保持缺测，不补零参与能量统计。
- **橙色线及标识：处理边缘影响区。**暂定为每段端部`max(20秒, 该段时长的3%)`；这是本项目的检查规则，并非文献保证。橙区保留数值供查看，正式拟合仍应排除或检验。
- **短段未处理标识：原始计数存在，但当前处理链未输出。**不会伪装成档案没有记录。
- 最多2点的临时插值即使最终重新遮蔽缺样，仍可能影响周围滤波样点；标识以外也不意味着已经证明无任何处理影响。

处理图不归一化、不人为去尖峰，也未实施Zhang等的仪器跳变拟合或S14采集畸变修复。纵轴为**名义**nm/s或nm；增益命令历史尚未完整重建，暂不能视作绝对幅值已认证。

## 6. 如何据此推进质量控制与散射分析

第一步是检查原始图：信号何时开始增长，是否有宽缺口、平台、孤立跳变、周期性异常，以及不同分量是否一致。第二步检查处理图：异常是否被响应校正放大，尾波起伏是否紧贴原始缺口，所谓“能量峰值”是否对应单个可疑脉冲。第三步才在选定的连续时窗内比较频带、包络和散射模型。

本轮修正的是展示和处理步骤的可追溯性，**不修改此前“正式反演频带尚待认证”的状态**。新增显示覆盖率不等于新增可靠观测；不得以显示空白减少来宣称质量改善或有效事件数增加。也不能从可疑削顶或量化自动推断某条文献清晰记录完全不可用。

后续准入需要：逐时增益与响应模式核对；尖峰、仪器跳变和S14畸变分类；短缺口策略与边缘窗敏感性；相同物理量和相同时间窗下的前噪声/增长段/晚尾波检查。只有通过这些步骤的窗口才用于尾波能量、峰值时间、衰减率及散射参数拟合。

特别注意：Nunn2024图1的约25秒平滑，与该文后续速度平方包络的约445秒平滑是不同分析设置；Onodera等的起算时间和局部峰值定义也不完全一致。本页暂不生成混合这些定义的“统一上升时间”。
