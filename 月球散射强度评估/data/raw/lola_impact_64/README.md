# 本次撞击路径地图使用的 LOLA 数据

下载与核验日期：2026-10-29。

## 官方产品与本地文件

- 产品：NASA/PDS，LRO LOLA GDR，`LDEM_64`，V3.1，产品生成日期 2019-03-15。
- [官方 IMG](https://pds-geosciences.wustl.edu/lro/lro-l-lola-3-rdr-v1/lrolol_1xxx/data/lola_gdr/cylindrical/img/ldem_64.img)
- [官方标签](https://pds-geosciences.wustl.edu/lro/lro-l-lola-3-rdr-v1/lrolol_1xxx/data/lola_gdr/cylindrical/img/ldem_64.lbl)
- `ldem_64.lbl`：原样保存的官方标签。
- `ldem_64_lat40N_18S_native_int16.img`：从官方全球 IMG 按 HTTP 字节范围下载的北纬 40°—南纬 18°、全经度原生条带，171,048,960 字节。它是条带，不是完整全球 IMG，不可直接套用全球标签行数读取。
- `ldem_64_W38_E40_S18_N40_native.npz`：从条带直接提取的 3,712 行 × 4,992 列原生裁片，西经 38°—东经 40°、南纬 18°—北纬 40°。NPZ 内保存整数 DN、像元中心经纬度、比例因子和参考半径。
- 完整数据来源、21 次 HTTP 范围检查、每块与文件 SHA-256：`results/impact_terrain/lola_data_provenance.json`。

## 正确读取

官方全球数据为 11,520 × 23,040 网格，16-bit **小端有符号整数**（`<i2`），每行 46,080 字节，全球应为 530,841,600 字节。本次条带为全球零起算行 `3200:6912`，从北向南存放。

- 高程（m）= `DN × 0.5`，相对于半径 1,737,400 m 的参考球；**不能再减去 1,737,400 m**。
- 行中心纬度 = `90 − (行号 + 0.5)/64`。
- 全球列中心经度 = `(列号 + 0.5)/64`，东经正，原始 0°—360°。
- 裁片将西经对应的原始末尾列与 0°以东列拼接，转换为东经正的 −180°—180°表示。没有插值，也没有重复 0°经线列。
- 原生采样为 64 像元/度，即 0.015625°。南北间距约 473.802 m；东西间距约为该值乘 `cos(纬度)`。

这是一份以激光测高为基础、由 LOLA 团队制作的网格产品；标签说明生产过程中对覆盖不足区域使用了 `surface` 插值，并提示纬度带边界可能存在伪影。因此，“原生网格”指发布产品的采样，不代表每格均有独立激光测量，也不等于处处达到 474 m 的真实空间分辨率。本项目没有进一步插值或把绘图像素数当作新地形信息。

## 拒绝复用的旧文件

旧 `data/raw/dem/ldem_64_float.img` 为 1,109,721,088 字节，而其官方标签要求 1,061,683,200 字节。文件尺寸不符，**本轮所有地图均未使用该文件**。原件保留以便追溯，旧 README 对其可用性的描述不应再用于新结果。

## 图形编码与适用边界

- 所有地图共用 −5 至 +5 km 高程色标；本裁片实际高程范围 −4.913 至 +4.4415 km，未截去超范围像元。
- 轻阴影采用西北方向 315°、太阳高度 45°、垂向比例 1；只辅助读出坡面起伏，不表示反照率或散射强度。
- 图中蓝实线框是全部记录的几何覆盖，橙虚线框是近距候选。两者完全相同时叠合显示，不是两套不同边界。
- 实线路径表示文献清晰记录；虚线路径及台站名后的 `*` 表示该事件—台站组合在文献中为低信噪比。台站状态随事件变化，不是该台站始终低信噪比。
- 所有框沿用事件审计的 50 km 几何缓冲。它不等于已验证的尾波模拟范围或 PML 厚度。
- 没有添加小于 2 km 的地形点名。2 km 在赤道约只有 4.2 个原生网格，不能把最窄可见纹理当作精确断层、沟谷或地质单元边界。
- “高地”是地质地貌背景名称，不意味着每个台站的参考球高程为正；例如 S15 位于盆地边缘区域，其落点仍在较低位置。具体高程见 `results/impact_terrain/site_height_checks.csv`。
