# LOLA DEM

`ldem_64_float.img` 和 `.lbl` 来自 NASA/PDS LOLA GDR cylindrical float product，0.015625° 网格、11520×23040，像元间距约 0.474 km，像元值为相对 1737.4 km 参考半径的高度（km）。当前区域总图读取该高分辨率数据，并为显示按 2 倍抽样；`ldem_4_float.img` 保留为低分辨率快速检查版本。

来源目录：[NASA/PDS LOLA GDR cylindrical float products](https://pds-geosciences.wustl.edu/lro/lro-l-lola-3-rdr-v1/lrolol_1xxx/data/lola_gdr/cylindrical/float_img/)。
