# 散射模型建模包

本包包含文献范围、CGFD3D 建模方案、六类模型定义、三组通用 NetCDF 材料预览、88 个计划运行和波形评分接口。

当前 CGFD3D 正式波场运行数为 0。材料预览不是完整事件计算域，也不是已验证的 CGFD3D 原生输入。
用户已决定沿用 CGFD3D，待提供生产 test.json 和介质导出接口后接入。不要将当前材料/代码检查当作实际波形拟合或区域反演结果。

从 docs/08_区域散射参考模型与参数范围.md 和 docs/09_CGFD3D散射建模与波形筛选方案.md 开始阅读。
重建依赖：Python、NumPy、SciPy、netCDF4、Matplotlib。
在解压目录运行 python code/build_scattering_models.py，然后 python code/validate_and_plot_model_design.py。
运行前创建 reports 目录（已随包包含报告）。
所有长度单位为米，速度为 m/s，密度为 kg/m³。NetCDF 维序 depth,y,x，depth 向下。
论文参数与本项目探索范围分开记录。地图标注 2 km 门槛不限制地下相关尺度。
