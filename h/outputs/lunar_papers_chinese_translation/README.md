# 五篇月震论文中文对应稿

## 文件说明

本目录给出五篇论文的中文对应稿。中文稿按原论文的章节编号、公式编号、表格编号和图号组织，并保留原文页码提示，便于与英文 PDF 对照阅读。

正文、摘要、方法、结果、讨论、结论、表格和图注均译为中文。参考文献表不逐条翻译，作者-年份引用保持原样；数学公式沿用原符号。原 PDF 中因字体编码造成的个别符号错误，按版面和上下文校正。

## 使用建议

- 精读时同时打开英文 PDF 和对应中文稿，按图号、表号和页码跳转。
- 引用论文时应引用英文原论文，中文稿仅作为阅读辅助。
- 对存在多种译法的术语，正文优先使用本表中的统一译法。
