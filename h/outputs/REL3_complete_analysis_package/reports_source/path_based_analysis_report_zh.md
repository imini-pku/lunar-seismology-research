# 三条射线的传播路径地形分析

本分析使用震源至台站方向的地表投影直线路径，沿路径累计地形高差与平均绝对坡度；它比仅使用终点台站高程更接近波场实际经历的自由表面起伏。当前结果仍不是三维弯曲射线或有限频率 Fresnel 体积积分。

## 传播路径结论

1. 射线1沿途最平滑，路径累计高差和平均绝对坡度都远低于射线2、3，因此地形对其振幅和能量的系统削弱较弱。
2. 射线2在约60–80 km穿越显著低洼区及其边缘，最强特征是散焦和能量损失；相近距离下，地形模型峰值和总能量可显著低于平坦模型。
3. 射线3在约30–55 km就快速积累起伏，且整体平均绝对坡度最大，更容易形成多脉冲、相位分裂和较长尾波。
4. 路径累计高差与峰值振幅、总能量呈强负相关，与90%能量持续时间呈强正相关，且显著强于终点台站高程关系。
5. 平均绝对坡度主要控制完整波形畸变、包络展宽和尾波，而不是一个统一的首波或峰值走时修正。
6. 地形把相干直接脉冲的一部分能量转换为反射、绕射、模式转换和多路径能量，因而常见组合是峰值下降、局地总能量下降、持续时间增加。
7. 射线3的粗糙度最大，但射线2某些位置的能量损失更强，说明地形曲率、坡向、盆地几何及聚焦/散焦不能由单一高差完全表示。
8. 约50 km的同距离比较已能显示终点高程不足：射线1和2路径高差较小且M3/M1能量接近1，而射线3路径高差约3 km时能量可降至约0.1量级。
9. 约100 km的同距离比较进一步显示，射线2与3的高起伏路径均造成更强的M3/M1振幅和能量下降以及显著持续时间增长。
10. 地形与随机散射具有饱和型非加性；波列已被随机散射展宽后，地形新增的边际作用通常小于无散射背景中的地形作用。
11. 当前路径是地表投影直线。下一步应使用有限频率 Fresnel 走廊、波场快照和能量通量，把路径宽度、曲率、坡向及关键地形段纳入解释。
