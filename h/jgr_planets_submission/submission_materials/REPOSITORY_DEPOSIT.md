# Required final repository step

AGU requires the data and software needed to evaluate and reproduce the paper to be placed in a repository that issues a persistent identifier. The local package intentionally does not invent one.

Before journal upload:

1. Confirm the exact production manifest for M3 and M4, especially random-medium amplitude, correlation lengths, depth range, random seed, and source file.
2. Deposit `data/raw`, `data/derived`, `code`, `config`, and `provenance` in Zenodo, Figshare, or an institutional repository.
3. Obtain the DOI and replace the final paragraph of the manuscript's Open Research section with the repository citation.
4. Add the archived dataset/software citation to the reference list.
5. Rebuild the manuscript and verify the DOI link.

Suggested repository title: **Data and software for "Surface Topography and Shallow Heterogeneity Control Early Lunar Seismic Envelopes but Not the Apollo Long Coda"**.
