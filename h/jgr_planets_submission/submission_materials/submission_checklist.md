# JGR: Planets pre-submission checklist

- [x] Title, authors, affiliations, and corresponding author present.
- [x] Three Key Points, each under 140 characters and without unexplained abbreviations.
- [x] Abstract under 250 words.
- [x] Plain Language Summary under 200 words.
- [x] Keywords included.
- [x] Main text uses a single factorial narrative and distinguishes evidence from interpretation.
- [x] Figures and captions are embedded in the combined manuscript.
- [x] Supporting Information is separate.
- [x] Competing claims from the old tracked-change manuscript removed.
- [x] Apollo comparison uses one shared three-component scale per model.
- [x] Claim-to-evidence matrix and checksums included.
- [ ] All authors confirm names, affiliations, author contributions, and funding.
- [ ] Exact M3/M4 production manifest confirmed.
- [ ] Data/software package deposited and DOI inserted in Open Research.
- [ ] Repository dataset/software citation added to References.
- [ ] Corresponding author performs final Word proof and journal portal metadata check.
